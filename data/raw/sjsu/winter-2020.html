Winter 2020 Class Schedule

There are three different types of modes of instruction: Fully Online, Hybrid, and In-Person (definitions linked). 

Real-time class listings, including textbook and course information, are found at one.sjsu.edu by searching for 'Class Search' in the Search Box. Some classes have multiple class notes, but this website only displays the first class note. A full list of class notes can be found in the Class Search and clicking on the class section title. 

If the class note indicates that the class has multiple meeting patterns, please review in your MySJSU the courses additional meeting patterns dates and times - only one meeting pattern is included in this schedule.
